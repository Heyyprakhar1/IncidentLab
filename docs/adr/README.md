# Architectural Decision Records (ADR)

Architectural Decision Records capture significant engineering decisions made during the development of IncidentLab.

Each ADR explains:

- Context
- Decision
- Alternatives
- Consequences

## Current ADRs

| ADR | Status |
|------|--------|
| ADR-001 — Monorepo Strategy | Accepted |

New ADRs should only be created for decisions that significantly impact the architecture or long-term evolution of the platform.
